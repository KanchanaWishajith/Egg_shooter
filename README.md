# Egg Shooter 🥚🔫

Welcome to **Egg Shooter**, an exciting and fun first-person shooter game built in Unity! Battle against waves of enemies using an arsenal of weapons, grenades, and melee attacks. 

## Features 🌟

*   **Solo Offline Gameplay:** Dive straight into the action with a fully functional single-player offline mode.
*   **Weapon System:** Choose from a variety of weapons! The game features an advanced gun system including ranged weapons, projectiles, and melee combat.
*   **Enemy AI:** Face off against different types of enemies, including simple melee waddlers and ranged attackers.
*   **Loadout & Skins:** Customize your experience with different player skins and weapon loadouts managed through the Main Menu.
*   **Interactive Environments:** Features maps with interactive elements, ammo pickups, health management, and more.
*   **Mobile Support:** Includes input mappings and controls tailored for mobile devices.

## Getting Started 🚀

### Prerequisites
*   Unity Editor (Ensure you have a compatible version installed, e.g., Unity 2021/2022 LTS).

### Installation
1.  Clone this repository to your local machine:
    ```bash
    https://github.com/KanchanaWishajith/Egg_shooter.git
    ```
2.  Open Unity Hub.
3.  Click on **Open** and navigate to the cloned `Egg_shooter` directory.
4.  Wait for Unity to import all assets and dependencies.

### Playing the Game
1.  In the Project window, navigate to the `Assets/Scenes` folder.
2.  Open the **MainMenu** scene to start from the beginning.
3.  Press the **Play** button in the Unity Editor.
4.  Choose your loadout and dive into the game!

## Project Structure 📁

*   `Assets/Scripts/`: Contains all the C# scripts driving the game logic (Player Controller, AI, Weapons, UI).
*   `Assets/Scenes/`: Contains the game levels and menu scenes.
*   `Assets/Models/` & `Assets/Prefabs/`: 3D models and reusable game objects.
*   `Assets/Animations/`: Animation controllers and clips for players and enemies.
*   `Assets/Audios/`: Sound effects and background music.
*   `Assets/Skins/` & `Assets/WeaponData/`: Scriptable objects and materials for customization.

## Controls 🎮

*   **Movement:** WASD / Left Joystick (Mobile)
*   **Look:** Mouse / Right Screen Drag (Mobile)
*   **Shoot/Attack:** Left Mouse Click / On-screen Button
*   **Throw Grenade:** G / On-screen Button
*   **Pause:** Escape
